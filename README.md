# Social Media 

A modern social media platform built with Next.js 14, TypeScript, Prisma, and MySQL. This application provides a complete social media experience with user authentication, posts, likes, follows, and real-time interactions.

##  Features

- User Authentication - Register, login, and JWT-based sessions
- Posts Management - Create, read, update, and delete posts with image upload
- Social Interactions - Like posts and follow other users
- Personalized Feed - View posts from users you follow
- Real-time Notifications - Get notified about likes and follows
- Responsive Design - Mobile-first responsive UI
- Type Safety - Full TypeScript support

##  Tech Stack

- Frontend: Next.js 14, React, TypeScript, Tailwind CSS
- Backend: Next.js API Routes, Prisma ORM
- Database: MySQL
- Authentication: JWT, bcrypt
- File Upload: Multer alternative with custom implementation
- State Management: Redux Toolkit

##  Prerequisites

- Node.js 18+ 
- MySQL database
- npm or yarn
